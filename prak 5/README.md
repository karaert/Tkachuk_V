# Project Title: Django Site

## Description
This is a Django project named "site". It serves as a template for building web applications using the Django framework.

## Installation
To set up this project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   cd site
   ```

2. Create a virtual environment:
   ```
   python -m venv venv
   ```

3. Activate the virtual environment:
   - On Windows:
     ```
     venv\Scripts\activate
     ```
   - On macOS/Linux:
     ```
     source venv/bin/activate
     ```

4. Install the required packages:
   ```
   pip install -r requirements.txt
   ```

## Usage
To run the development server, use the following command:
```
python manage.py runserver
```

Visit `http://127.0.0.1:8000/` in your web browser to see the application in action.
